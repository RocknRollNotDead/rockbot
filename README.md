Навайбкодил бота для управления группой. В основном функции бота это хранить музыку, минуса, текста, и тд. Также есть возможность фидбека, рассылки и тд.
В общем, вот навигационный месседж. Есть три уровня доступа - обычный слушатель или гость, участник группы и админ.

Навигация

/start — главное меню

/bandinfo — вся информация о нас

/allsongs — все песни

/search — поиск песен

/concerts — концерты


Уведомления
/subscribe — подписаться


Управление контентом

/addsong — добавить песню

/addalbum — собрать альбом

/addevent — добавить концерт

/addrehearsal — добавить репетицию

/rehearsals — список репетиций

/addnews — опубликовать новость

/createpoll — создать опрос

/inbox — отзывы слушателей

/stats — статистика

/togglefeedbacknotify — вкл/выкл автоуведомления о фидбеке


Администрирование
/members — участники группы

/requests — запросы на участие

/unblock — заблокированные пользователи

/setrecipient — кто получает уведомления о запросах

/setbandinfo — установить информацию о группе

/addbandinfo — добавляет текст к существующей информации о группе

/updateimport — импорт песен из директории

Нейросетка также навайбкодила мне инструкцию как сделать так, чтобы этот бот заработал у вас для вашей группы https://github.com/RocknRollNotDead/rockbot/blob/master/README_DEPLOY.md.
